# 공개 소스 검증 상태

## 2026-09-20 첫 소스 공개

현재 개발 작업 폴더의 소스를 MIT 라이선스로 공개합니다. 기존 `v0.1.0-beta.1` 설치 파일과 이 소스의 버전 일치는 검증하지 않았습니다. 설치 EXE와 기존 미디어·라이선스는 유지합니다.

Windows x64·Node.js 24.11.1에서 별도 checkout에 `npm ci`를 수행했습니다. 앱 코드·테스트·빌드 스크립트는 원본과 바이트가 일치합니다. 공개용 README·개발 안내·Git 제외 규칙과 외부 고지를 함께 정리했습니다.

- `npm run check`: 타입 검사 통과, 테스트 **1,608 통과·2 실패·11 조건부 생략**, 총 1,621개, 772.661초입니다.
- 실패 1: `tests/github-service.test.ts`의 백업 복원 후 fixture worker 시작 대기입니다.
- 실패 2: `tests/growth-lifecycle.test.ts`의 자동 복구 취소 검사에서 PGlite 초기화가 중단됐습니다.
- 코드·제한시간 변경 없이 위 두 테스트를 직렬로 개별 재검증해 **2/2 통과**했습니다. 원래 전체 검사 실패의 원인은 확정하지 않았으며, 전체 검사를 다시 통과한 것으로 표현하지 않습니다.
- 별도 `npm run build`: 타입 검사와 웹 빌드 통과입니다. 번들 크기 경고는 남아 있습니다.

실제 컨테이너·모델 실행, 전체 네이티브 컴파일, 설치·업데이트는 이번 공개 작업에서 재검증하지 않았습니다. 과거 문서의 `.verification/` 경로는 로컬 기록이며 이 저장소에 포함하지 않습니다.
